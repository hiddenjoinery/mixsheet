# OpenSpec changes

Each subdirectory is a proposed or in-flight change. Use the
`openspec-propose` skill to scaffold a new change folder. After a
change ships, move it under `archive/`.

## Required files per change

- `proposal.md` — what we want and why (≤ 800 words)
- `design.md` — architecture decisions and tradeoffs
- `tasks.md` — implementation checklist
- `spec.md` — observable contracts (SHALL/MUST + scenarios)
